# World Map

Drop the world map image into `00_System/Assets/Maps/`, then replace the example below with a real `leaflet` code block (change the fence from `text` to `leaflet`).

```text
id: irotahl-world
image: [[irotahl_world.png]]
height: 700px
lat: 50
long: 50
minZoom: 1
maxZoom: 4
defaultZoom: 2
unit: miles
scale: 1
```

Markers you place on the map can link straight to location notes in `01_Atlas`.
